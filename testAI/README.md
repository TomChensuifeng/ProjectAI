# testAI

展示五代十国主要政权的**疆域示意地图**与**政权存续时间轴**的前端项目。

## 当前能力
- 地图示意展示：显示主要政权的大致空间分布（教学示意，不是测绘级历史边界）。
- 时间轴展示：以 907–979 年统一时间轴显示各政权起止区间。
- 年份滑块筛选：拖动年份可查看该年份仍存在的政权并在地图高亮。
- 交互联动：点击地图区域或政权卡片可聚焦单个政权。
- 可访问性：卡片与地图区域支持 Enter / 空格键触发。

## 使用方式
```bash
cd testAI
python3 -m http.server 8000
```

浏览器访问：`http://localhost:8000`

## 说明
- 本项目用于学习和演示，历史疆域边界受时期变化与资料口径影响较大。
- 若你希望做“精确边界版”，可在后续接入历史 GIS / GeoJSON 数据并替换当前示意路径。
